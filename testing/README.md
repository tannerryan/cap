# Test fixtures

The Oasis files are examples from the CAP 1.2 specification. The NWS tornado
files come from the [National Weather Service CAP bulletin][nws]. The other NWS
files are snapshots from the [NWS alerts API][nws-api]. The ECCC files are
snapshots from the [Environment and Climate Change Canada Datamart][eccc]. The
Pelmorex files are legacy NAADS CAP-CP samples from its [LMD user
guide][pelmorex].

[nws]: https://www.weather.gov/documentation/tb-alerts-CAP-Supporting-360-Character-and-Spanish-WEA

[nws-api]: https://www.weather.gov/documentation/services-web-alerts [eccc]:
https://eccc-msc.github.io/open-data/msc-data/alerts/readme_alerts-datamart_en/
[pelmorex]:
https://alerts.pelmorex.com/wp-content/uploads/2020/09/NAADS-LMD-User-Guide-R10.0.pdf
